<objective>
## Goal
Extend MediaKitPlaybackDeck to support configurable exclusive output mode on Windows, with shared mode as the default and reliable fallback. Wire the exclusiveOutput flag from PlaybackDependencies.createDeck based on platform and settings.

## Purpose
This is the foundation for Windows WASAPI integration. The MediaKitPlaybackDeck already has an `exclusiveOutput` constructor parameter but it's hardcoded to `false`. This plan makes it configurable and wires it through the existing playback architecture.

## Output
- Modified MediaKitPlaybackDeck that accepts and uses exclusiveOutput flag
- Modified PlaybackDependencies.createDeck to pass exclusiveOutput based on Windows platform and settings
- Preserves shared mode as default behavior
</objective>
