<objective>
## Goal
Implement a Windows playback mode status reporting mechanism similar to the Android USB audio status, allowing the UI to display the active output mode (shared/exclusive) and negotiated format details.

## Purpose
Users need to know what audio mode is actually active. Android has `usbAudioStatus` and `usbHardwareVolume` for this. Windows needs an equivalent mechanism that reports the requested mode and (in Phase 2) the actually negotiated format.

## Output
- WindowsAudioStatus class in music_playback_deck.dart
- windowsAudioStatus ValueNotifier for UI consumption
- MediaKitPlaybackDeck updates status on configureOutput and source load
- Integration with MusicPlayerHandler for access in audio info sheet
</objective>
